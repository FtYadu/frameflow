# FrameFlow - API Keys Setup Guide

## 🔑 Getting Your API Keys (10 minutes)

### 1. Anthropic Claude ($5 Free Credit) ⭐ RECOMMENDED
**Best for lead generation and content creation**

1. Go to: https://console.anthropic.com
2. Sign up with email
3. Navigate to "API Keys" 
4. Click "Create Key"
5. Copy your key: `sk-ant-api03-...`
6. **Free Credit**: $5 included (enough for ~1,000 requests)

**Model Recommendations:**
- **Claude 3.5 Sonnet**: Best quality for lead generation
- **Claude 3.5 Haiku**: Fastest and cheapest for simple tasks

---

### 2. OpenAI GPT
**Great alternative, very popular**

1. Go to: https://platform.openai.com
2. Sign up/Login
3. Go to "API Keys" → "Create new secret key"  
4. Copy your key: `sk-...`
5. **Billing**: Add $5 minimum to start

**Model Recommendations:**
- **GPT-4o**: Best quality
- **GPT-4o Mini**: Cheapest option

---

### 3. Google Gemini (Free!)
**Free tier with generous limits**

1. Go to: https://makersuite.google.com/app/apikey
2. Sign in with Google account
3. Click "Create API Key"
4. Copy your key: `AIza...`
5. **Free Tier**: 15 requests/minute, 1,500/day

**Model Recommendations:**
- **Gemini 1.5 Flash**: Super fast and free
- **Gemini 1.5 Pro**: Higher quality

---

### 4. OpenRouter (Access to Multiple Models)
**One API key for multiple providers**

1. Go to: https://openrouter.ai
2. Sign up
3. Go to "Keys" → "Create Key"
4. Copy your key: `sk-or-...`
5. **Billing**: Pay-per-use, very affordable

**Benefits:**
- Access to Claude, GPT, Llama, Mistral all in one
- Often cheaper than direct APIs
- Great for experimentation

---

## 📱 Adding Keys to FrameFlow

1. **Open FrameFlow app**
2. **Login/Register**
3. **Tap AI Settings** (brain icon in dashboard)
4. **Add your API keys**:
   - Tap provider (Anthropic, OpenAI, etc.)
   - Enter your API key
   - Keys stored securely in iOS Keychain
5. **Configure agents**:
   - Choose which model each agent uses
   - Set creativity levels
   - View cost estimates

## 🔒 Security Notes

- **Keys are encrypted** in iOS Keychain (bank-level security)
- **Never share** your API keys publicly
- **Rotate keys** monthly for best security
- **Monitor usage** in provider dashboards to avoid unexpected charges

---

## 🆘 Troubleshooting

**Key not working?**
- Check for typos (keys are long!)
- Verify key has correct permissions
- Ensure billing is set up (for paid providers)

**High costs?**
- Switch to cheaper models (Haiku, Mini, Flash)
- Adjust agent frequency in settings
- Monitor usage in AI Settings

**Need help?**
- Check provider documentation
- Most providers have excellent support
- Start with free tiers to test
